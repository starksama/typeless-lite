# Product

## Register

product

## Users

Verba is for macOS users who write constantly across other apps and want speech to become usable text without switching context. They are usually in a focused work session, speaking into a laptop microphone or headset, then returning the output to a document, chat, browser, terminal, or editor.

## Product Purpose

Verba starts dictation quickly, transcribes speech, optionally polishes the text, and inserts it into the app the user was already using. Success means a new user can grant permissions, add an API key, set a shortcut, and produce their first transcript without hunting through settings.

## Brand Personality

Calm, precise, capable. The product should feel like a refined desktop utility: dense enough for repeated use, clear enough for first-run setup, and quiet enough to stay out of the user's work.

## Anti-references

Avoid promotional SaaS dashboards, cute rounded controls, generic glowing microphone widgets, verbose setup tutorials, noisy diagnostics panels, and vague errors that say something failed without naming the next action.

## Design Principles

1. The primary workflow stays in front: speak, process, insert.
2. Setup copy must name the exact next action, especially for macOS permissions and shortcuts.
3. Settings are a compact control surface, not documentation.
4. Visual texture should come from disciplined materials, borders, and state indicators, not random decoration.
5. Future AI features such as translation or text conversion should fit the existing transcript and polishing model without turning Home into a dashboard.

## Accessibility & Inclusion

Target a keyboard-accessible desktop UI with visible focus states, compact but readable text, reduced-motion support, and status messages that remain understandable without color alone. Permission setup must work for new `.dmg` installs on macOS and must distinguish Accessibility from Microphone because they use different OS flows.
